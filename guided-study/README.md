# Private guided simulator lessons

The HTML entrypoints load a local player; initial load opens no organ and plays no sound. The owner-approved M02 narration is reused as12 unchanged MP3s. Other course narration remains pending. The electrical and respiratory previews are manual scenes with no audio clock.

`session.js` owns Guided/Explore state and only the separate `cmt.guided-lesson.v1` storage key. `player.js` supplies one awaited RAF while playing; actual `HTMLAudioElement.currentTime` owns time. Models have no competing native playback loop in Guided. Each cue supplies a full deterministic scene. Hold/phase/electrical anchors use the existing numerical model; cycling derives time from the audio position. Full circulation teaching stops span many beats. These are educational reconstructions, not patient-specific or clinical predictions.

Play requires an explicit gesture. Load/seek/replay/back/next/return are paused. Touching simulator controls first releases Guided ownership, pauses audio and saves the guided position. Return restores that position and its scene without unexpected sound. Independent exploratory snapshots cannot overwrite lesson progress. Async preparation uses cancellation contexts and generation/DOM ownership guards. Corrupt saved guided data is preserved with an error; unrelated progress keys are never cleared.

`HeartV3Study.guided` and `CardiorespiratoryStudy.guided` expose prepare/apply/capture/restore/pause around the existing teaching modules. Existing models, original HRA geometry, respiratory appearance, removed-node-diagram policy and microscopic lessons remain owned by those modules. `scene.detail` explains bindings with incomplete source geometry; vessel-wall layers, blood constituents and coronary-flow theory are not fabricated as new anatomy. The four-chamber section does not expose every vessel or semilunar cusp; its connected circulation map remains explicitly schematic.

M02 audio identity, source Library IDs, original course identity, machine anchors, source hashes and warnings are in `assets/M02-provenance.json` and `M02-cue-anchors.json`. Offline PocketSphinx forced alignment used imposed approved text and sourced authored vocabulary additions. Its10ms frame granularity is not an accuracy guarantee. Listening/pronunciation review remains pending, including the M02.03 atrioventricular duration flag. The aligner and its dependencies are scratch tooling, not application dependencies. No generation, provider calls or keys are used by this player.

Run `node tools/guided-study/session.cjs`, `node tools/guided-study/player-ui.cjs` and, with an existing local HTTP server and cloud Playwright installation, `PORT=8859 node tools/guided-study/browser.cjs`. The latter uses actual delivered media and anatomical scenes; CPU tests alone do not establish rendered behavior. Physical iPad/Safari and specialist review remain unexecuted. Cursor review remains unavailable; independent GPT reviews are separately identified.
